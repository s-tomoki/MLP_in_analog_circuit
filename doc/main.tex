\chapter{ニューラルネットワークの電子回路実装}

\section{実験の目的}
本実験では、オペアンプを用いた加算回路により、簡易的な人工ニューロン（パーセプトロン）を構成し、その動作を検証します。

ニューロンの基本式は、入力 $x_i$ と重み $w_i$、バイアス $b$ を用いて以下のように表されます。
$$y = f\left( \sum_{i=1}^{n} w_i x_i + b \right)$$

\begin{cautionbox}{警告：電源の接続について}
    オペアンプのプラス電源（$V_{CC}$）とマイナス電源（$V_{EE}$）を逆に接続すると、素子が破損し発熱する恐れがあります。電源を入れる前に必ず配線を確認してください。
\end{cautionbox}
