# 課題 3: MNIST 手書き数字の識別

## 1. 目的

- 課題 2 で作った `nn_core`(誤差逆伝播法と勾配降下法で学習する MLP)を使い、**実際の画像データ** を識別する。
- 画像をネットワークの入力に変える前処理(縮小・二値化)と、クラスを出力に対応させる方法(one-hot ・ argmax)を理解する。
- 学習用とは別のテストデータで正解率を測り、「学習した」ことを確かめる方法を身につける。
- 目的の違う 2 種類のテスト(**ユニットテスト** と **スモークテスト**)を使い分ける。

## 2. 背景

### 2.1 MNIST

MNIST は、0〜9 の手書き数字の画像データセットです。 1 枚は 28x28 画素のグレースケール画像(画素値 0〜255)で、学習用 60,000 枚・テスト用
10,000 枚にそれぞれ正解ラベル(0〜9)が付いています。

この課題では、アナログ回路への実装を見据えて、既定では次のように **小さく・単純に** して扱います。

| 項目 | 既定 | 変更するには(`main.py`) |
| --- | --- | --- |
| クラス | 0 と 1 の 2 クラス | `--classes 0 1 2 ...` |
| 画像サイズ | 4x4 平均プーリングで 7x7 = 49 画素 | `--size 28` |
| 画素値 | 二値化(0.5 より大きければ 1、それ以外は 0) | `--no-binarize` |
| ネットワーク | `[49, 2, 2]`(隠れ層 2 ニューロン) | `--hidden 16` など |
| 活性化関数 | 隠れ層・出力層とも ReLU | `--activation` / `--output-activation` |
| L2 正則化 | あり、$\lambda = 0.01$ | `--no-l2` / `--l2-lambda` |

### 2.2 前処理

1. 画素値を 255 で割って 0〜1 の実数にする。
2. **平均プーリング**: 28x28 を 4x4 画素ずつのブロック(7x7 個)に分け、各ブロックの平均を 1 画素にする。
3. **二値化**: 0.5 より大きい画素を 1、それ以外を 0 にする。
4. 7x7 の画像を 1 列(長さ 49)に並べ、ネットワークの入力ベクトルにする。

### 2.3 出力層と one-hot

出力層にはクラス数と同じ数のニューロンを置き、ニューロン $k$ を「クラス $k$ らしさ(スコア)」に対応させます。 学習では、正解のクラスだけ 1、他は 0
のベクトル(**one-hot ベクトル**)を目標にして、課題 2 と同じ二乗誤差を小さくします。

| ラベル(2 クラス) | one-hot |
| --- | --- |
| 0 | `[1, 0]` |
| 1 | `[0, 1]` |

### 2.4 推論(argmax)と「未決定」

推論では、スコアが最も大きいクラスを答えにします(**argmax**)。 回路なら「一番大きな出力を選ぶ」だけで実現できます。

出力層が ReLU の場合、全クラスのスコアがちょうど 0 になることがあります。 このとき単純に argmax をとると「クラス 0」と答えてしまうので、
**全クラスのスコアが同じなら「未決定」(`UNDECIDED = -1`)** とし、正解率では不正解として数えます。

> 多クラス分類では、出力に softmax 関数、損失に交差エントロピーを使うのが一般的です。 しかし softmax
> は層の全出力を使って計算するため、ニューロンごとに計算する `nn_core` の構成に合わず、回路でも最大値の選択で足ります。 この課題では、課題 2 の
> `nn_core` をそのまま使えるよう、ReLU 出力 + 二乗誤差 + argmax にしています。

### 2.5 学習の進め方

- **1 サンプルずつ更新**(課題 2 と同じ)。ただし MNIST ではサンプルが多く、同じ順番で使い続けると偏りが出るので、
  **エポックごとに順番をランダムに入れ替え(シャッフル)** ます。順番は識別器の乱数生成器 `rng` で決めるので、同じシードなら毎回同じ結果になります。
- **テストデータで評価**: 学習に使っていない画像で正解率を測ります。
  学習用データでの成績だけでは、「覚えただけ」なのか「見たことのない画像にも通用する」のかが分かりません。

## 4. 要件(API 仕様)

### `mnist_data.py`

| 名前 | 内容 |
| --- | --- |
| `load_mnist(cache_path=DEFAULT_CACHE)` | `((x_train, y_train), (x_test, y_test))` を返す。画像は shape `(N, 28, 28)` の uint8、ラベルは shape `(N,)`。手元に無ければ URL からダウンロードする(実装済み) |
| `preprocess(images, size=7, binarize=True)` | shape `(N, size*size)` の float 配列を返す(実装済み) |
| `select_classes(images, labels, classes)` | 指定した数字だけを取り出し、ラベルを `classes` 内の位置(0, 1, ...)に付け替える(実装済み) |
| `one_hot(labels, num_classes)` | shape `(N, num_classes)` の float 配列。正解のクラスだけ 1、他は 0 |

データは標準ライブラリの `urllib.request` で次の URL から取得し、`ex3/data/mnist.npz` に保存します(約 11 MB、2
回目以降はダウンロードしません)。

```
https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz
```

### `classifier.py`: `MnistClassifier(num_inputs=49, hidden=(2,), num_classes=2, seed=None, activation="relu", output_activation="relu")`

| 名前 | 内容 |
| --- | --- |
| `mlp` | 中身の `nn_core.MLP`(層構成 `[num_inputs, *hidden, num_classes]`) |
| `rng` | シャッフル用の乱数生成器(`np.random.default_rng(seed)`) |
| `predict_scores(x)` | shape `(N, num_classes)` のスコア(実装済み) |
| `predict(x)` | shape `(N,)` の整数配列。スコア最大のクラス。全クラスのスコアが同じなら `UNDECIDED`(-1) |
| `accuracy(x, labels)` | 正解率。`UNDECIDED` は不正解(実装済み) |
| `confusion_matrix(x, labels)` | shape `(num_classes, num_classes + 1)`。`[i, j]` は正解 `i` を `j` と予測した件数、最後の列は未決定の件数(実装済み) |
| `fit(x, labels, epochs, optimizer, l2_lambda=0.0, x_val=None, y_val=None, log=None)` | 学習して履歴 `{"loss": [...], "val_accuracy": [...]}` を返す(下記) |

`fit` の仕様:

- 各エポックで `self.rng.permutation(N)` の順番に全サンプルを 1 回ずつ使い、`self.mlp.train_step` で更新する(目標は
  one-hot)。
- `loss` にはエポックごとの損失の平均を、`val_accuracy` には(検証データがあれば)エポック後の検証データの正解率を追加する。
- `log` が与えられていれば、各エポックの後に `log(エポック番号(1 から), 履歴)` を呼ぶ。

### 使ってよいライブラリ

- 使ってよい: Python 標準ライブラリ(`urllib.request` など)、NumPy(図の保存に matplotlib、テストに pytest)
- 使ってはいけない: Keras、TensorFlow、PyTorch、scikit-learn などの機械学習フレームワーク

## 5. テストについて

### ユニットテストとスモークテスト

|  | ユニットテスト(`test_mnist_unit.py`) | スモークテスト(`test_mnist_smoke.py`) |
| --- | --- | --- |
| 目的 | 部品ごとの shape ・型・値の範囲・再現性を確かめる | 全体を通して動かし、「大きく壊れていないか」を手早く確かめる |
| データ | 乱数で作った少数の「画像」 | 実際の MNIST(0 と 1)を訓練・テストとも 500 件 |
| 学習 | 数件 × 数エポック。精度は問わない | 500 件 × 5 エポック。**正解率 90% 以上** を確認 |
| 時間 | 1 秒程度 | 数秒(初回はダウンロードの時間が加わる) |
| ネットワーク | 不要 | 初回のみ必要。取得できなければ **スキップ** |

スモークテストの合格ラインは、でたらめに答えた場合の正解率(2 クラスなので 50%)より明らかに高い 90% です。 全データでの学習や最高の精度は求めません(それは
`main.py` で確かめます)。 スモークテストには `smoke` マーカーが付いているので、次のように選んで実行できます。

```bash
pytest -m "not smoke" -v   # ユニットテストだけ(ネットワーク不要)
pytest -m smoke -v         # スモークテストだけ
```

### 穴埋めのテスト

本体が `pass` のテスト(4 関数)は、docstring の「条件」「期待」とコメントの「ヒント」に従って書いてください。

> **注意: 本体が `pass` のテストは、何も確かめずに「合格」になります。** 書き終えたら、実装をわざと間違えて(例: `predict` で argmax の
> `axis` を変える、`fit` でシャッフルをやめる)テストが失敗することを確かめましょう。

| テスト | 確かめること |
| --- | --- |
| `test_backward_gradient_shapes_and_types` | MNIST の大きさの入力でも、逆伝播で求まる勾配の shape ・型が正しく、値が有限であること |
| `test_predict_returns_labels_and_undecided` | `predict` が argmax を返し、同点のときは `UNDECIDED` を返すこと |
| `test_fit_is_reproducible` | 同じシードなら、シャッフルを含めて学習結果が完全に再現すること |
| `test_smoke_subset_training_beats_random_baseline` | 数百件・数エポックの学習で、ランダムより明らかに高い正解率になること |

スモークテストは固定のシード(`SEED = 0`)で合格することを確認しています。 `[49, 2, 2]` の ReLU ネットワークは隠れ層が小さいため、
シードによっては隠れ層のニューロンが常に 0 を出力する状態(dying ReLU)になり、学習に失敗します(試した範囲では 10 個中 2 個のシード)。 `fit`
のヒントどおり `self.rng.permutation` で順番を決めていれば、解答と同じ学習結果になります。

```bash
pip install numpy matplotlib pytest
```

```bash
cd ex3
```

### 学習スクリプト `main.py`

`ex3/` ディレクトリで実行します。エポックごとの損失とテスト正解率を表示し、最後に混同行列を表示して、 学習曲線とテスト画像 16 枚の予測例(誤り・未決定は赤)を
`result_<条件>.png` に保存します。

```bash
python src/main.py                                  # 既定: 0/1、7x7・二値化、[49, 2, 2]、ReLU、L2 あり
python src/main.py --no-binarize                    # 二値化しない
python src/main.py --size 28                        # 28x28 のまま(784 入力)
python src/main.py --classes 0 1 2 --hidden 8       # 3 クラス
python src/main.py --train-size 1000 --epochs 3     # 小さく試す
```

| 引数 | 説明 | 既定 |
| --- | --- | --- |
| `--classes` | 識別する数字(2 個以上) | `0 1` |
| `--size` | 入力画像のサイズ(`7` または `28`) | `7` |
| `--binarize` / `--no-binarize` | 二値化するか | する |
| `--hidden` | 隠れ層のニューロン数(複数可) | `2` |
| `--activation` / `--output-activation` | 隠れ層 / 出力層の活性化関数 | `relu` / `relu` |
| `--epochs` | エポック数 | `10` |
| `--learning-rate` | 学習率 | `0.01` |
| `--l2` / `--no-l2`、`--l2-lambda` | L2 正則化の有無と強さ | あり、`0.01` |
| `--train-size` / `--test-size` | 先頭から何件使うか | 全件 |
| `--seed` | 重みの初期化とシャッフルのシード | `0` |

### フル学習の想定実行時間の目安

全データ・既定のエポック数(10)で学習したときの実測値です(教材作成時の計算機: WSL2 上の Python 3.12、`--seed 0`)。 `nn_core` は 1
ニューロンずつ Python で計算するため、**時間はおおよそ「サンプル数 × エポック数 × ニューロン数・入力数」に比例** します。

| 条件 | 学習データ | 1 エポック | 10 エポック合計 | テスト正解率 |
| --- | --- | --- | --- | --- |
| 既定(0/1、7x7 ・二値化、`[49, 2, 2]`) | 12,665 件 | 約 0.6 秒 | **約 6 秒** | 97.1% |
| `--no-binarize` | 12,665 件 | 約 1 秒 | 約 10 秒 | 99.6% |
| `--size 28`(`[784, 2, 2]`) | 12,665 件 | 約 2 秒 | 約 22 秒 | 99.9% |
| 3 クラス(`--classes 0 1 2 --hidden 8`) | 18,623 件 | 約 3 秒 | 約 33 秒 | 91.3% |
| 10 クラス、`--hidden 32`(`[49, 32, 10]`) | 60,000 件 | 約 35〜40 秒 | **約 6〜7 分**(推定) | 42%(3 エポック時点) |
| 10 クラス、`--hidden 32`、シグモイド、`--learning-rate 0.5 --no-l2` | 60,000 件 | 約 60 秒 | **約 10 分**(推定) | 69%(3 エポック時点) |

「(推定)」は 3 エポック分の実測から見積もった値です。時間は計算機によって数倍程度変わります。10 クラスの学習を試すときは、まず
`--train-size 5000 --epochs 3` などで小さく試してから全データに進んでください。

## 7. NumPy と pytest の追加の API

### NumPy

| API | 説明 | 例 |
| --- | --- | --- |
| `np.argmax(a, axis=1)` | 各行で最大値の位置(列番号)を返す。`axis=0` なら各列で最大値の行番号 | `np.argmax([[1, 5], [7, 2]], axis=1)` → `[1, 0]` |
| `np.eye(n)` | n×n の単位行列(対角成分だけ 1) | `np.eye(3)[1]` → `[0., 1., 0.]` |
| `a[[2, 0, 2]]` | 整数の配列を添字にすると、その番号の行をまとめて取り出せる |  |
| `np.all(a, axis=1)` | 各行の要素がすべて `True` か |  |
| `a == a[:, :1]` | 各行の要素を、その行の先頭の要素と比べる(形の違う配列どうしの要素ごとの計算を「ブロードキャスト」と呼ぶ) |  |
| `rng.permutation(n)` | 0〜n-1 をランダムに並べ替えた配列 | `rng.permutation(4)` → 例 `[2, 0, 3, 1]` |
| `a.reshape(n, 7, 4, 7, 4).mean(axis=(2, 4))` | 28x28 画像を 4x4 のブロックに分けて平均する(平均プーリング) |  |
| `np.isin(a, values)` | 各要素が `values` に含まれるか |  |
| `np.isfinite(a)` | 各要素が有限の値か(`nan` や `inf` でないか) |  |
| `np.issubdtype(a.dtype, np.integer)` | 配列の要素が整数型か |  |

### pytest

| API | 説明 |
| --- | --- |
| `@pytest.fixture(scope="module")` | テストで使うデータなどを準備する関数(**フィクスチャ**)。テスト関数の引数に同じ名前を書くと、準備した値が渡される。`scope="module"` ならファイル内で 1 回だけ準備する |
| `pytest.skip("理由")` | そのテストを「スキップ」として終える。前提(データなど)がそろわないときに使う |
| `pytestmark = pytest.mark.smoke` | ファイル内の全テストにマーカーを付ける |
| `pytest -m "not smoke"` | 指定したマーカーが **付いていない** テストだけを実行する |
| `pytest -k one_hot` | 名前に `one_hot` を含むテストだけを実行する |

## 9. 発展課題(任意)

1. `--no-binarize` や `--size 28` にすると正解率と学習時間はどう変わるか。回路への実装との兼ね合いも考えよう。
2. 3 クラス以上(例: `--classes 0 1 2`)にすると、隠れ層は何ニューロン必要になるか調べよう。
3. `--seed` を変えて、学習に失敗する(dying ReLU になる)シードを探し、そのときの隠れ層の出力を調べよう。
4. 10 クラスで ReLU の正解率が上がりにくい原因の 1 つとして、重みの初期値(標準正規分布)が入力の数に対して大きすぎることが考えられる。 `Neuron`
   の初期化を He 初期化(標準偏差 $\sqrt{2 / \text{入力数}}$)に変えると改善するか試そう。
5. `--l2-lambda` を 0、0.001、0.01、0.1 と変えて、正解率と重みの大きさの関係を調べよう。
