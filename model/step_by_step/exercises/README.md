# ニューラルネットワーク演習

ニューラルネットワークを、機械学習フレームワークを使わず、ゼロから段階的に実装する演習です。

| ステージ | 課題 | 内容 |
| --- | --- | --- |
| 1 | [`ex1/`](ex1/) | ニューロン・層・ MLP の順伝播(Step 活性化)。手で設定した重みで NAND / XOR を作る |
| 2 | [`ex2/`](ex2/) | 誤差逆伝播法と勾配降下法による学習。シグモイド・ ReLU ・ステップ(STE)と L2 正則化で NAND / XOR を学習させる |

## ディレクトリ構成

```
ex<N>/            課題(穴埋め版)
  README.md       課題の目的・要件・実行方法・評価基準
  src/            穴埋めコード(この中の nn_core/ を実装する)
  tests/          テストコード(ex2 以降は一部が穴埋め)
ex<N>_answer/     解答版(src/, tests/ のファイル名は ex<N>/ と対応)
```

コアライブラリのパッケージ名は、どのステージでも `nn_core` です。

## 共通ルール

- 言語: Python 3.10 以上
- 使ってよい: Python 標準ライブラリ、NumPy (図の保存には matplotlib、テストには pytest を使います)
- 使ってはいけない: Keras、TensorFlow、PyTorch、scikit-learn などの機械学習フレームワーク

## 準備

```bash
pip install numpy matplotlib pytest
```

テストや `main.py` は、各ステージのディレクトリ(例: `ex1/`)に移動してから実行してください。
